# Admin Navigation Patch v1
Requires Academic Master Data Patch v1. Stop Django, back up the three affected files, and merge the backend folder into the project root. Run `python manage.py check`, then `python manage.py runserver` from backend with your environment activated. Sign into /admin/ and click Master Data Management or Open. Use the breadcrumb or Back to administration dashboard to return. The existing management links lead to programme, module, faculty and learner lists. No migrations, dependency changes, CSV imports or database reset are required. This patch changes config/urls.py to set the built-in admin site's index_template and adds an app-owned template that extends the original Django admin index. Existing URL routes are unchanged. The management page retains its existing forms and logic. If you have edited config/urls.py locally, merge the single index_template assignment rather than replacing your edits.
