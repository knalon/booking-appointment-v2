# Milestone 0.5 — React management, first slice
Requires combined professional qualification patch v1. No migrations or reseeding. Back up and merge backend/frontend/docs into project root. Run `python manage.py check`, `python manage.py runserver` from backend; `npm run dev` from frontend. Use http://localhost:5173 consistently; sign in through the linked Django admin login (proxied by Vite). Existing staff credentials only; no credentials embedded. Session authentication and CSRF protect new write endpoints. Vite proxy is development-only.

Faculty list and profile, add/edit/revoke expertise, dependent module/topic/qualification fields, read-only catalogue/learner/curriculum pages, read-only expertise integrity scan, links to existing Django Admin/CSV tools. New module choices default to taught modules; explicit option permits other active modules with verified expertise. Existing expertise module immutable. No automatic data repair or deletion. Django inline existing records filter topics and enforce validation; new inline records may still show all topics. Full React CRUD and CSV UI remain next increments. Existing import validation already rejects cross-module topics; not replaced. Audit scan is not a global database constraint; catalogue changes and direct database edits can still introduce inconsistencies. No new dependencies.

Optional local automated tests: `python manage.py test apps.directory.test_management_api` (Django test database creation privileges required). Test add/edit, wrong topic rejection, duplicate expertise, anonymous access. Run npm run build to verify frontend. Development proxy not production deployment.
