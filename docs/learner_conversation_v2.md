# Learner conversation v2
Baseline: Conversational NLP v1 already installed. Back up project and database; merge folders, stop and restart both servers. No new dependencies. Run `python manage.py check`, `python manage.py migrate`, `python manage.py test apps.nlp.test_nlp` from backend. Migration nlp.0002_final_result adds nullable JSON snapshot; old staff previews are retained but inaccessible in the chat UI and not presented as learner results. Old confirmed conversations have no versioned result; do not fabricate a snapshot. Legacy active drafts with numeric duration become fixed; null stays unspecified until explicitly clarified.

## Demo accounts
Only on a private local development instance, with DEBUG=True and fictional @example.invalid profiles, run `python manage.py provision_demo_learners --confirm DEMO-ONLY`. The command prints the username for each learner. Names are lowercased with spaces removed; collisions get a learner-ID suffix, existing linked users are not modified. Password 1234 is intentionally weak, for fictional local testing only. Never expose this instance to the Internet or use these passwords for real learners. The learner chat/login routes are disabled when DEBUG=False until production authentication is implemented. No new accounts are staff. Do not reseed: the reseed command refuses linked accounts. Log out of management before using /learner (or use another browser profile). Staff see Confirmed requests, not chat.

## Request workflow
Conversation is primary. Review/complete details expands below chat. Confirm saves a versioned JSON snapshot in MySQL, available in learner history and staff Confirmed requests (latest 100). No bookings or availability checks. Duration preference: null unknown, fixed with minutes, flexible with null minutes. Relative dates remain text. Microphone dictation is optional browser Web Speech recognition, not an OpenAI audio endpoint; the browser may send audio to its own provider after consent. Language support varies. Transcript is editable before sending. Typing remains available. Existing .env and API key unchanged.
