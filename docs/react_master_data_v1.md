# React Master Data Management v1 (0.5.2)
Baseline: React Faculty Curriculum Filter v3, applied after the combined professional qualification patch and React faculty edit patch. Merge backend/frontend/docs into the existing project root. No migration or reseed is required. Back up first. Run `python manage.py check` and restart Django, then `npm run dev` and hard-refresh localhost:5173. Use existing staff credentials in React.

## Features
React sign-in/sign-out, dashboard, faculty profile create/edit/archive/restore, expertise add/edit/revoke eligibility, learner and four catalogue create/edit/archive/restore, CSV import preview/confirm, export, blank templates, recent import history, integrity review. No Django Admin links in the management workspace. Existing developer admin is retained. Faculty qualification removal sends a backend impact response before any write; confirm removes dependent qualification links and incompatible teaching assignments, preserves expertise topics/verifier/review date, and revokes eligibility when the last expertise qualification is removed. Shared valid teaching modules remain selected. Catalogue archival may require resolving active references first. No hard deletion; no bulk archive selection in this release (CSV status updates are available). The app uses existing local staff authentication, not institutional SSO. Import history shows latest 200 batches. Curriculum sequence swaps can use CSV import. Existing technical APIs remain available for developers; this patch does not add universal DB constraints or a new audit log for manual edits.

## Tests
Run `python manage.py test apps.directory.test_management_api apps.directory.test_master_api` using a MySQL account allowed to create a separate test database. Do not run tests against the live database. Run `npm run build` from frontend. Verify sign-in, all management pages, new records, archive/restore, CSV preview and confirmation, and qualification removal with cancel/confirm. Check that cancelled changes are not saved, shared modules remain, and expertise is retained but ineligible if it loses its last qualification. No live integration test was run during packaging.
